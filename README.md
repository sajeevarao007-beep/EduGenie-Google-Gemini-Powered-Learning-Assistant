# 📘 EduGenie Learning Assistant – Setup Guide

Before getting started with the **EduGenie Learning Assistant** project, ensure you have a basic understanding of Python programming, REST APIs, and fundamental concepts of Artificial Intelligence and Natural Language Processing (NLP).

Familiarity with FastAPI, HTML, CSS, and working with APIs will be helpful for developing and integrating different modules of the application.

Additionally, install Visual Studio Code (VS Code) or any preferred code editor for efficient coding and project management. Basic knowledge of Git and virtual environments is also recommended for dependency handling and version control.

---

## 🧰 Prerequisites

- Python 3.10+
- FastAPI framework
- HTML & CSS (basic templating)
- Google Gemini API Key
- Uvicorn (ASGI server)
- Jinja2 (templating engine)
- Git & GitHub

---
